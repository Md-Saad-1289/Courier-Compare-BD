# Courier-Compare-BD
Courier Compare BD is a lightweight web app for comparing courier delivery costs in Bangladesh.  
It helps users find the cheapest and fastest courier instantly.  
Built using HTML, CSS, and JavaScript with no backend required.  
It calculates total cost based on weight, COD, and delivery zone.  
Users can compare multiple courier services in one view.  
It includes coverage checking for different districts.  
Search history is saved using LocalStorage.  
The UI is fully responsive for mobile, tablet, and desktop.  
Designed with a modern SaaS-style clean interface.  
This project is ideal for e-commerce and logistics planning.
